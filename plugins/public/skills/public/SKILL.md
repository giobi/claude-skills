# /public — Public Sites Manager

CRUD for static mini-sites and reports served from a `public/` directory.

**Before using:** read your config from `wiki/skills/public.md`.

## Rule zero — the URL is a fact you read, never a fact you compose

Writing the files and making them reachable are two different steps, and only the
platform knows the resulting address. So:

1. **Never invent, guess, or pattern-match a public URL.** Not from the brain slug,
   not from the folder name, not from an old link you saw in a chat, not from
   `PUBLIC_URL` in `.env` (stale in many installs).
2. **Get the URL from the driver** — `share.py list` / `share.py publish` for
   `share-cli`, or `{base_url}/{slug}/` for `static`. That output is the only
   address you may give the user.
3. **Verify before delivering.** `curl -s -o /dev/null -w '%{http_code}' <url>` must
   return 200. A 302 to a login page means it is *not* public.
4. **If it isn't published, say so.** "Non è pubblicato, il link non esiste ancora"
   is a correct answer. A plausible-looking dead link is not — it costs the user
   several rounds of 404s before they find out you were guessing.
5. **Never explain the platform's behaviour from intuition.** If a link fails, run
   the check and read the error. Do not tell the user *why* it failed (or what to
   click) unless you verified it.

## Configuration

`wiki/skills/public.md`:

```yaml
---
driver: share-cli          # share-cli | static
public_dir: public
template_dir: public/template
# solo driver: static
base_url: https://public.example.com
---
```

## Driver `share-cli` — ABChat installs

`public/` is not served by a web root. Each folder is published on demand and gets
an **opaque token URL** (`{install}/share/{token}/…`) that expires. The token is
generated by the app and cannot be derived from anything the brain knows.

```bash
python3 .claude/skills/public/share.py list                        # cosa è pubblico ORA, con URL veri
python3 .claude/skills/public/share.py publish sito-cliente        # pubblica, stampa l'URL
python3 .claude/skills/public/share.py publish sito-cliente --days 7 --password segreta
python3 .claude/skills/public/share.py revoke  sito-cliente        # spegne il link
```

Facts about this driver, verified — do not extrapolate beyond them:

- **A published folder serves everything under it**, at any depth. If the whole of
  `public/` is published, `…/share/{token}/report.html` and
  `…/share/{token}/report/index.html` both work. **A file directly inside `public/`
  does not need to be wrapped in a folder with an `index.html`** — that is a myth.
- `index.html` is served automatically when the URL points at a folder — so a
  folder is still the tidier shape for a multi-file site.
- Publishing is **idempotent per folder**: re-publishing extends the expiry and
  keeps the same link. Revoking and re-publishing mints a **new** token.
- Max 90 days. An expired publication returns an error page, not the content.
- The user can also publish from the web UI. Either way, `share.py list` is the
  truth — check it before saying anything about what is or isn't public.

## Driver `static`

`public/` is served by a web root at `base_url`. The URL of a site is
`{base_url}/{slug}/`. Nothing to publish: writing the file is enough. Still verify
with `curl` before handing over the link.

## Commands

```
/public list                    What is published right now, with real URLs
/public create <slug> <title>   Create new mini-site from template
/public update <slug>           Update existing site
/public delete <slug>           Delete a site
/public publish <slug>          (share-cli) Publish and return the link
/public revoke <slug>           (share-cli) Kill the link
/public rebuild-index           Regenerate the index page
```

## Rules

1. **Use templates.** Check `{template_dir}/` for available templates before creating.
2. **Self-contained HTML.** CSS inline, Google Fonts via CDN only.
3. **No sensitive data.** `public/` is readable by anyone holding the URL. Never
   passwords, tokens, personal data, or client-confidential material. Ask the user
   before publishing anything that mentions a third party.
4. **Kebab-case names.** All folder names lowercase with hyphens.
5. **Main file = `index.html`.** For multi-file sites.
6. **Only facts you sourced.** A published page is a deliverable: every number,
   dimension, name, and date in it must come from a document, a message, or the
   user — not from a plausible reconstruction. If a value is missing, leave a
   visible gap ("da verificare") instead of filling it in. An invented figure on a
   page the user forwards to a contractor or a client is worse than an empty cell.

## Template System

Templates live in `{template_dir}/`. Each is a self-contained HTML file with placeholder blocks.

When creating a new site:
1. List available templates: `ls {template_dir}/*.html`
2. Let user pick one (or suggest based on content type)
3. Copy template → `{public_dir}/{slug}/index.html`
4. Replace placeholders with real content
5. Publish (`share-cli`) or note the path (`static`), then **verify with curl**
6. Report the URL you got back — not one you built

## Available Blocks (common across templates)

| Block | CSS Class | Use for |
|-------|-----------|---------|
| Key numbers | `.stat-grid` | Metrics, KPIs |
| Text | `.text-block` | Paragraphs |
| Highlight | `.highlight-box` | Conclusions, recommendations |
| Status list | `.status-list` | Activities with badges |
| Data table | `.data-table` | Structured rows |
| Key-value | `.kv-card` | Reference pairs |
| Links | `.link-list` | Clickable links |

## Output

After creating/updating, report the verified URL and how long it lasts:

```
Pubblicato: <url dal driver>   [HTTP 200 verificato]
Scade: 06/08/2026
Template: {template_name}
File: index.html [+ asset]
```

Full links, always with `https://` — a bare domain isn't clickable in a terminal.
